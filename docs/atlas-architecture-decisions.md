# Atlas architecture decision index

The enduring decision authority remains [`.ai/DECISIONS.md`](../.ai/DECISIONS.md).
This requested index links the unification decisions rather than copying a second
handbook. Full request: [master brief](requirements/ATLAS_MASTER_SYSTEM.md).

- Modular monolith with Core contracts and module-owned services.
- Inventory ledger truth; available-now and projected future supply are distinct.
- Financial fields need server-side capability checks, including indirect read models.
- Continuous compatible releases, backed up and verified on the live VPS.
- Explicit supplied Home requirements supersede older launcher-only preferences;
  implement operational Home using existing attention/My Work, without new records.

New implementation rationale and acceptance are recorded with each release in
CURRENT_STATE and the relevant owner guide. Open questions remain debt, not decisions.
