# Quality workspace research — 8 October 2026

Michael requested substantial Quality improvements informed by established platforms,
with ease of use and security retained. Consulted official product/documentation sources:

- [Qualio CAPA and nonconformance](https://www.qualio.com/product/capa-management-software): connected detection, investigation, corrective work and close-out; visibility of responsibility and progress; reusable workflows and linked quality evidence.
- [MasterControl Process overview](https://currentcloud.onlinehelp.mastercontrol.com/2024.1/en_us/Content/Process/MasterControl_Process_Overview.htm): structured processes for nonconformances, deviations, corrective actions, change control and complaints, with information from other systems.
- [Reliance platform](https://www.octave.com/products/asset-performance-management/reliance) (official ETQ platform URL redirects here): broader quality-management coverage across connected processes. Broad vendor coverage is a benchmark, not an assertion Atlas now implements every advertised function.

Design conclusions applied to Atlas:

| Need | Implementation |
| --- | --- |
| Easy reporting without a giant mandatory form | Start with issue/requirement/source/severity; disclose context, evidence and investigation |
| Responsibility and time visible | Canonical company member ownership, target dates, action register and assigned/overdue filters |
| Investigation connected to action | Guided optional five whys, supported root-cause confirmation, prevention and linked corrective work |
| Completion distinguished from effectiveness | DONE before VERIFIED; criterion and evidence required; ineffective work stays unresolved |
| Controlled close-out | Closure review, major/critical cause/action gates, closed-record lock and reasoned reopening |
| Trustworthy records | Server tenant/capability/entitlement checks, submitted-version locking, atomic audit and preserved metadata |
| Trustworthy inspection outcomes | Every configured answer checked, explicit manual pass/fail, history, failed hold/NCR connection |

The supplied Atlas master brief §§126–134 additionally calls for operational quality
connections, richer checks and supplier performance. This delivery strengthens existing
owners; it does not replace them with cloned quality customers/products/documents.
The full supplier-scoring, document/photo/signature checks, calibration, approvals and
cross-planning propagation requirements remain separately unverified or unfinished.
