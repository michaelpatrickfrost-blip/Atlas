# Atlas bundled fonts

Atlas uses Nunito for shared rounded interface typography and Geist Mono for
code and technical identifiers. `next/font/local` loads bundled variable fonts
without live Google CSS or runtime third-party requests. Full source character
coverage is retained; licences are included beside the files.

Nunito files come from the official Google Fonts repository at pinned commit
`8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`, under the SIL Open Font License 1.1.
Normal and true italic both cover weights 200–1000.

- `Nunito-Italic-Variable.ttf`: https://raw.githubusercontent.com/google/fonts/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/nunito/Nunito-Italic%5Bwght%5D.ttf; SHA-256 `b520cc871868b0acfca1beda875df7f4a44ebce914f8a89f83977fc9c09529c8`
