# Atlas bundled fonts

Atlas uses Inter for interface text, Newsreader (an editorial serif) for page
and section titles, and Geist Mono for code and technical identifiers.
`next/font/local` loads bundled variable fonts without live Google CSS or
runtime third-party requests. Licences (SIL OFL 1.1) are included beside the files.

Inter and Newsreader were taken from the official Google Fonts repository
(main branch, 20 October 2026):

- `Inter-Variable.ttf`: https://github.com/google/fonts/raw/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf; SHA-256 `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`
- `Newsreader-Variable.ttf`: https://github.com/google/fonts/raw/main/ofl/newsreader/Newsreader%5Bopsz,wght%5D.ttf; SHA-256 `8a08d13f8a6c0d51be379a60af84f945f65369a67e509ee3c3bdcc421254d7c1`
