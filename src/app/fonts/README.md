# Atlas bundled fonts

Atlas uses Outfit (a rounded geometric sans) for interface text, Fraunces (a soft
editorial serif with optical sizing) for page and section titles, and Geist Mono
for code and technical identifiers. `next/font/local` loads bundled variable
fonts without live Google CSS or runtime third-party requests. Licences
(SIL OFL 1.1) are included beside the files.

Outfit and Fraunces were taken from the official Google Fonts repository
(main branch, 20 October 2026):

- `Outfit-Variable.ttf`: https://github.com/google/fonts/raw/main/ofl/outfit/Outfit%5Bwght%5D.ttf; SHA-256 `fc7287273e66929776e2ba54f144fe699080bec29f61bf649d70d871468aeade`
- `Fraunces-Variable.ttf`: https://github.com/google/fonts/raw/main/ofl/fraunces/Fraunces%5BSOFT,WONK,opsz,wght%5D.ttf; SHA-256 `177ff6c0f14e5550a3c624247cd1189611d4eb65d000b14944c63d967958abbb`

`51303ca9e8ac9dcea7b12d307ba568fd0e6fcfca`, under its accompanying SIL OFL licence.
