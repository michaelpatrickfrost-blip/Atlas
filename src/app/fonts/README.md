# Atlas bundled fonts

The existing Atlas families are self-hosted from the official Google Fonts
repository at pinned commit `51303ca9e8ac9dcea7b12d307ba568fd0e6fcfca`, under their accompanying SIL OFL licences.
Use `next/font/local` so production builds do not depend on live Google CSS or
font-query parsing. Full variable fonts retain all supplied character coverage.
